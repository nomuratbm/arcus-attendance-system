DynamoDB Member Fetch Technical Flow:

1. Module Setup: Initialize DynamoDBDocumentClient using AWS SDK.
2. Route Execution: Handle GET request dynamically (force-dynamic).
3. Request Validation: Extract and trim 'uuid' query param; return 400 Bad Request if missing.
4. Env Validation: Read DYNAMODB_TABLE_NAME; return 500 Internal Server Error if missing.
5. DynamoDB Query: Send QueryCommand for partition key PK = :pk (supports MEMBER#uuid and raw uuid formats).
6. Response Handling:
   - Item missing: Return 404 Not Found ({ valid: false, error: "Member not registered in the system" }).
   - Item found: Return 200 OK ({ valid: true, member: Item }).
7. Exception Handling: Catch AWS/network errors and return 500 Internal Server Error.

Simpler terms:
Get UUID (check QR code and trim uuid)
    if no uuid -> return 400 bad qr.
    if no table name -> return 500 server error.
    query DynamoDB by PK (try MEMBER#uuid then raw uuid)
    if no member in db -> return 404 member not found.
    if member found -> return 200 member found + member data.
    if aws error -> return 500 server error.
